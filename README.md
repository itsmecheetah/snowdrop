## Installation
1. [Install Quickshell](https://quickshell.org)
2. Download the latest release (or clone this repository) to `~/.config/quickshell`.
3. Run `qs -c snowdrop` at startup, or however makes sense for your configuration ([here's mine as an example](https://github.com/itsmecheetah/nixos/blob/main/common/hypr/hyprland.lua), see line 21)

## Configuring 
All Snowdrop config options can be found & modified at `~/.config/snowdrop-shell/config.json`.

See `CONFIGURING.md` for descriptions of each option.

Keep in mind that Snowdrop is still in development, meaning that breaking changes may occur!
